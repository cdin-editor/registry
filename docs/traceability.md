## Evidence boundaries and limitations

- The Phase 9 clean-room integration test exercises Product Definition YAML validation,
  Catalog Index/Release Metadata schema validation and digest verification, Resolver,
  real temporary Git commit collection, Workspace publication, Manifest Verify and
  byte-identical Replay.
- Catalog metadata fetches use a fixed four-worker default (maximum four), preserve
  index-order processing and join workers on cancellation/failure. Git fetching and
  source copying remain sequential.
- Metadata and Git-object GC use explicit pins/leases and fail-closed reference
  snapshots. Broader long-duration discovery/replay/GC interleaving stress remains
  an operational hardening qualification, not a claim made by the current tests.
- Native tests cover Linux, macOS and Windows publication/permissions. Parent-directory
  fsync and uniform crash/power-loss durability are not provided.
- HTTPS allow-lists and DNS checks do not enforce deployment egress. Signing,
  attestations, SBOMs, component vulnerability scanning and build sandboxing are
  outside the Registry guarantee.

A workflow result applies only to the exact commit, tasks and platforms that ran.
